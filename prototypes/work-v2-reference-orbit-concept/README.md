- 不复制录屏中的服装图片、平台品牌、白底配色或文案。

## 本版设计系统

- 颜色：曜石黑、石墨灰、雾银、浅灰；粒子、光晕和可选自定义鼠标全部为中性色。
- 字体：标题使用 500 字重；导航、时间、正文、操作提示均为 400 字重，只用字号与灰度建立层级。
- Logo：按经历开始时间从左到右排列为赫里文化、庭澜美术馆、鲸海拾贝、豆包爱学、Gauth；Logo 下不显示名称、数据或成绩；悬停时 Logo 自身放大并出现 28 颗单色粒子。
- 时间弧线：无文字的单色 S 形轨迹连接五个节点；鼠标横向移动时弧线整体右向漂移，亮段同步沿轨迹推进。
- 信息区：左侧大标题，右侧共享经历读数；所有列从同一条隐形顶线开始，使用统一列间距，公司名称保持单行；不使用贯穿页面的长横线。
- 移动端：Logo 改为无标签的横向吸附轨道，共享信息在页面底部纵向展开。

## 事实边界

- 豆包爱学与 Gauth 属于同一生产体系的国内 / 海外分支。
- 庭澜美术馆官方公众号主页仍缺可核验的主页分享链接或二维码，因此该节点继续保留待核对状态，不跳转到非官方文章。
- 履历文字沿用现有真实简历数据，不增写、不推断。

## 本轮轨迹校正

- 固定主轨迹逐一穿过五个 Logo 的几何中心；鼠标位移只驱动雾化余波与单段流光，避免节点与轨迹再次脱离。
- 主轨迹改为低对比、圆头的颗粒虚线，并放松高低起伏；保留时间动势，但避免笔直钢丝般的“紧绷感”。
- 流光采用单段长间隔，移动到轨迹右侧时不会在左侧回卷出残留亮线。

## 响应轨迹与数据粒子

- 鼠标在页面任意位置移动时，局部波形会按横向位置追随，并根据鼠标高低产生克制的上下牵引；固定主轨迹仍负责连接五个 Logo。
- 悬停或键盘聚焦 Logo 时，波形焦点吸附到节点中心，亮段与雾化余波同步抵达，不会因 Logo 放大而脱线。
- 每个粒子星环混入两条简历中可核验的数据或项目成绩，保持单色、细字与低密度：赫里 `EAST2046 / 米兰设计周`；庭澜 `100+ 位艺术家 / 风格分类・初筛`；鲸海拾贝 `600+ 学员 / AI 漫剧 SOP`；豆包爱学 `40+ 完整产出 / 返工率 −50%`；Gauth `8 门历史课 / 课程设计 Owner`。
