# ABOUT · Identity Spectrum

张可欣个人网站的 ABOUT 分区原型。页面使用经过确认的简历事实，将内容组织为三段连续场景：

1. `IDENTITY`：本人照片的半调光谱化呈现、个人定位与四项核心能力。
2. `EXPERIENCE`：可交互经历轨迹与量化成果，按时间从左到右排列。
3. `SYSTEM`：将能力表达为一条持续运转的生产链，并提供前往 WORK / IP 的下一步入口。

入口：`index.html`

## 事实边界

- 未写入未确认的教育经历、电话、邮箱或社交平台链接。
- 经历、时间、职位和量化成果均来自 `docs/00-source-of-truth.md`。
- 个人照片使用简历中的本人照片进行半调风格处理；AYAO 仅作为个人 IP 状态组件出现。

## 交互

- 鼠标附近粒子产生光谱色变化。
- 悬停四项能力时切换方法说明。
- 经历节点悬停 / 聚焦后更新事实详情与轨迹脉冲。
- 点击 AYAO 小组件切换黑龙角创作状态。
- 量化数据滚动进入视口后计数。
- 《未知星系》为用户点击后启用的低音量环境声，避免违反浏览器自动播放限制。
- 支持键盘焦点与 `prefers-reduced-motion`。
