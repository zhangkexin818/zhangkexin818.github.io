# ARCHIVE V1 · 版本地层

这一版将用户明确要求保留的“网站如何形成”变成 ARCHIVE 主内容，而不是额外导航项或截图墙。

## 内容依据

- `assets/drafts/`：从实际历史原型统一截取的同视口页面，不是杜撰过程图。
- `assets/works/`：来自既有作品集和 IP 页已经确认使用的真实作品素材。
- 取舍记录：只写入本轮沟通中已经明确确认过的设计决定。

## 关键交互

- 首屏版本地层可用滚轮、箭头、键盘和点击切换；再次点击当前层会放大查看。
- 鼠标轨迹与切换动作会生成低密度铜色粒子。
- 作品、网页草案、取舍记录共享一条可拖动胶片。
- 页面之间通过多层圆弧材质接力，不使用直线硬切或大面积虚化。
- 提供移动端布局、键盘焦点与 `prefers-reduced-motion` 降级。
