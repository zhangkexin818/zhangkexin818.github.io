# PERSONAL ORBIT / HOME 实现规范

## 页面任务

首页负责建立身份、方法与去向，不把项目详情压缩成密集卡片。用户先理解“把 AI 创作变成可协作、可上线的内容系统”，再从代表项目、原创 IP、版本档案、关于我四条路径进入独立页面。

## 视觉系统

- Paper `#FFFFFF`：主背景
- Carbon `#090A0B`：主文字与深色舞台
- Ink `#141618`：正文
- Mineral `#777A7D`：次级信息
- Hairline `#D9DBDA`：分隔线
- Portfolio Violet `#64159A`：来自作品集第 2 页的主紫，用于白底界面的唯一强调色
- Luminous Violet `#8B2CC2` / Deep Plum `#300048`：仅用于深色舞台的交互高光与暗部层次
- Media `#08070B` / Media Ink `#F3F1F7`：来自作品集第 1–3 页的冷黑与银白

颜色占比以 86% 中性白、12% 黑与灰、最多 2% 紫色为准。工作台内部的功能状态色不扩散到全站品牌界面。

## 页面结构

1. Orbit Calibration：首次访问时显示轨道校准加载页，可点击核心提前完成或直接跳过。
2. World in Progress：粒子成字入口，支持移动扰动、按住聚合、点击在文字与轨道形态之间变形，并自动演示一次轨道重组；进入正文时从身份票按钮扩张为白色页面。每次重新进入首页都可看到，只有 `?intro=0` 或父页面从其他章节启动时跳过。
3. 白色编辑式首屏：大字号命题、说明文字、开放式去向标签、两个主动作。
4. 右侧能力路径与像素分身：作为身份索引，不做装饰性仪表盘。
5. Selected System：滚动时从嵌入画幅平滑扩展为沉浸舞台，承接真实项目入口。
6. World in Progress 运行记录：深色收尾区，保留真实天数与版本数。

共享侧栏和导航结构不在本页修改范围内；连续页面只根据 HOME 的白色背景调整其现有配色可读性。

## 核心交互

- 去向标签使用测量后的滑动指示器；支持点击、左右方向键与焦点状态。
- 标签切换同步更新说明和目标链接，不在首页堆叠各页面内容。
- 标题关键词有克制的 WarpText 响应，指针尾迹只使用 Portfolio Violet。
- 像素分身支持悬停与点击状态切换。
- Selected System 画幅绑定滚动进度，尺寸、圆角、遮罩和元信息连续变化。
- 顶部滚动进度线固定显示，颜色为 Portfolio Violet。
- `prefers-reduced-motion` 下取消位移和追踪动画，直接显示稳定状态。

## 字体系统

- 中文标题：`Noto Sans SC` 470 左右，回退到 `Source Han Sans CN` / `DengXian`。
- 中文正文：`Noto Sans SC` 350–400，保持更细的灰度和更舒展的行距。
- 英文导航与数字：`Aptos` / `Inter` / `Helvetica Neue`，使用 350–500 字重。
- 首页 H1 不再使用 700 以上粗体；字重、字距和行高共同建立层级，不依靠加粗制造冲击。

## 响应式与可访问性

- 桌面基准：1600 × 1000；移动基准：390 × 844。
- 页面不得横向溢出，标题、路径标签和动作区在窄屏自然换行。
- 所有交互入口使用原生按钮或链接，并具备清晰的焦点样式与可读标签。
- HOME 既可独立打开，也可嵌入根目录的连续页面；嵌入时隐藏内层重复页头。
