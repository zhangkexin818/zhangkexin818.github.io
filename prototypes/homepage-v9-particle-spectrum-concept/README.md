# Homepage V9 · PERSONAL ORBIT

这是直接覆盖更新后的当前首页原型；v7 稳定副本仍保持不变。

## 当前结构

- 进入网站前先出现约两秒的全屏轨道校准页；轻触星核后，《未知星系》会在加载阶段开始播放，右上角可选择“静音进入”。若访客不操作，页面仍会自动静音进入，不形成阻塞。
- 首屏只保留左上角 `PERSONAL ORBIT`、`WORK / IP / ARCHIVE / ABOUT`、中央粒子标题与纸质身份牌。
- 中央粒子标题采用历史备选 `WORLD IN PROGRESS`：桌面两行，手机三行；只借用 v7 的“粒子成字”构图，不恢复旧版导航。
- 粒子标题采用双层渲染：预渲染密集点阵确保静止时清楚可读，轻量动态关键词负责鼠标接触时的光谱、散开与回弹。
- 粒子默认低亮度黑白，鼠标接触区域出现局部光谱、排斥、旋转与回弹。
- 粒子微文字使用事实底稿中的真实关键词：AIGC、内容策略、产品、课程、分镜、场景、提示词、工作流、PGC、UGC、Gauth、豆包爱学、AYAO、佛小仙等。
- 首页 `WORK` 与身份牌“进入”按钮已经接入确认后的 `work-v2-reference-orbit-concept` 经历页；首页与 WORK 页提供双向返回，不再停留在只有粒子标题的占位状态。
- 身份牌头像有三种状态：默认无角、悬停黑龙角观察者、点击黑龙角惊讶创作者。
- 页面末尾是与首屏同源的夜蓝黑运行记录区，不占用首页首屏。
- 左下角提供《未知星系》常驻音乐开关；在加载页轻触星核后保持播放，直到访客手动暂停，并在内部导航切换期间保持当前状态。

## 真实数字

- `本站已运行`：从 `2026-08-10 00:00（Asia/Shanghai）` 动态计算完整天数。
- `网页草案已保留`：当前工作区实际保留的 6 套网页原型目录。
- 数字在第一次进入视口时递增一次并停止；减少动态效果模式直接显示最终值。

## 交互

- 移动鼠标：产生局部光谱接触区。
- 点击粒子场：增强一次短促能量脉冲。
- 点击 WORK / IP / ARCHIVE / ABOUT：粒子重组为短标签，身份牌退出。
- 点击 PERSONAL ORBIT：恢复 `WORLD IN PROGRESS` 粒子标题与身份牌。
- 悬停 / 聚焦头像：显示黑龙角观察者状态。
- 点击头像：短暂切换黑龙角惊讶创作者状态。
- 点击 `SOUND 《未知星系》`：淡入 / 淡出程序化生成的环境音乐；标签页隐藏时暂停，返回时仅在访客此前开启过音乐的情况下恢复。
- 滚动进入页脚时，固定声音控件平滑抬高并进入预留的声音缓冲带，避免与指标说明、`VERSION LOG` 或返回链接碰撞。

## 性能原则

- Canvas 像素比受限，主循环约 45fps 封顶。
- 密集字形预渲染到离屏 Canvas，每帧只复制图层；动态层减少到约 1250 个桌面粒子 / 520 个手机粒子。
- 绝大多数动态粒子使用轻量方点绘制，只保留少量关键词文字。
- 指针离开且粒子回到目标后停止动画循环；页面隐藏时暂停更新。
- 手机端减少粒子数量，并优先保证三行标题辨识度。

## 文件

- `index.html`：语义结构、身份牌与末尾运行记录。
- `styles.css`：加载页、首屏、头像三态、暗色运行记录与响应式规则。
- `app.js`：加载流程、双层 Canvas 粒子、原创 Web Audio 音乐、导航、头像反应与一次性数字动画。
